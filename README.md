# SPM Task Manager

SPM Task Manager is a lightweight task tracking application prepared for the Software Project Management GitHub Workflow lab.

## Project Overview

The application demonstrates a collaborative GitHub workflow for planning, developing, reviewing, merging, and releasing a stable version of a small task manager.

## Core Features

- Create and view project tasks
- Track task status across a simple workflow
- Document team contribution rules
- Manage releases using semantic versioning

## Branching Strategy

- `main`: stable release-ready code
- `dev`: integration branch for reviewed work
- `feature/*`: feature branches used for active development

## Current Sprint Focus

Prepare a stable task manager foundation for version `v1.0.0`.
